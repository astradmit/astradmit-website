# Resources content

Every article or video on the Resources page is one Markdown file in `content/posts/`.

- Files whose names start with `_` are templates and are never published.
- Add `draft: true` to the details at the top of a file to keep it hidden until it is ready.
- Pictures go in `site/assets/img/` (name them like `post-2026-11-14-title.jpg`).

See the Astradmit Website Update Guide for step-by-step instructions.
